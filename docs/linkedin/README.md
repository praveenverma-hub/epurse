# LinkedIn assets

This folder contains the source and upload-ready files for the official ePurse LinkedIn Company Page.

- `LINKEDIN_PAGE_KIT.md` — final Page copy, launch posts, governance, and checklists
- `epurse-linkedin-logo-400.png` — Page logo
- `epurse-linkedin-cover-1512x256.jpg` — preferred Page cover
- `epurse-linkedin-cover-4200x700.jpg` — high-resolution cover master for future exports
- `epurse-linkedin-launch-post-1200x627.jpg` — launch post graphic
- `generate_assets.py` — deterministic asset generator

Run the generator from the project root:

```bash
python3 docs/linkedin/generate_assets.py
```

Review the Page logo and cover inside LinkedIn's current desktop and mobile previews before publishing.
